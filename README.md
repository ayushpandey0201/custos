# Custos

> Runtime trust layer for AI agents & models: policy, drift, and risk signals fused into ALLOW / BLOCK / REVIEW decisions, with full audit trail.

## Quickstart

```bash
docker-compose up --build
```

Then run the fintech demo:

```bash
cd examples/fintech_demo
./README.md   # follow steps
```

See `docs/architecture.md` for the full design (source of truth) and `docs/adr/` for key decisions.
